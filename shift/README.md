# 渉外局 シフト管理（本祭支援ツール 試作）

たびマップの本祭支援ツールに入れる予定の「シフト作成・管理」を、先に**単独のサイト**として試すためのものです。
地図（`index-google.html`）とは別に動き、地図側のファイルには手を入れていません。

- 対象：渉外局（約50人）。局（局長・副局長）・GS課（約15人）・広報課（約30人）
- 期間：2026年11月4日(水)〜9日(月)の6日間（本祭の期間と、その前後）
- 開き方：公開先 **https://ysnagaeiku-byte.github.io/tabi-map/shift/** を開く。手元では `shift/index.html` をブラウザで開くだけでも動きます（サーバーは不要）
- 日付の区分は「11/4〜6 準備、11/7・8 本祭、11/9 片付け」と仮に置いています。違うときは「⋯」→設定→日付と区分で直せます

## 画面

| 画面 | 内容 |
|---|---|
| **日別** | 横が時刻、縦がメンバー。1日分のシフトを棒で表示 |
| **6日間** | メンバー×日付の一覧。1マスに入り〜終わり・休憩・担当 |
| 全体／局／GS課／広報課 | 上の切り替えで、課ごとに分けて見る |

ひと目で分かるようにしたこと：

- **役職**：名前の左に色付きのバッジ（局長＝金、副局長＝橙、課長＝赤、副課長＝桃、班長＝青、一般＝灰の枠だけ）。行の左端にも同じ色の線。「役職で色分け」にすると、棒も役職の色になります
- **入りと終わり**：棒の左端に入り、右端に終わりの時刻。棒が短いときは棒の横に「9:00–10:00」（押すとその棒の編集）。スマホでは名前の下にも「入り–終わり 休憩の始まり」を表示
- **休憩**：棒の中の斜線が休憩（棒の色が透けるので誰の休憩か分かる）。幅があれば「休12:00」、もっと広ければ「休 12:00–12:45」。6日間の画面ではいつも時刻つき
- **人数**：日別の下に、30分ごとの勤務中の人数（休憩中を除く）。その30分の中で**一番少ないとき**の人数で、途中で人数が変わる枠には黄色の下線（パソコンではマウスを重ねると、多いときの人数も出ます）。全体のときは課ごとの行も
- **重なり**：同じ人の時間が重なると黄色と黒の枠と「重複」。重なった棒は上下に分けて、両方の端が見えるように

## 追加・修正のしかた

| したいこと | パソコン | スマホ |
|---|---|---|
| 追加 | 空いている所をドラッグ（クリックでも可） | 空いている所をタップ |
| 時間を変える | 棒の左右の端をドラッグ | 棒をタップして編集 |
| ずらす・別の人へ | 棒をドラッグ（上下で別の人へ） | 棒をタップして編集 |
| 編集・削除 | 棒をクリック | 棒をタップ |
| 6日間の画面で | マスを押すと追加（1件あるマスはその編集）。もう1件足すときはマスの隅の＋ | 同じ |
| 何人もまとめて | 「まとめて追加」（人×日を選んで一度に） | メニュー「⋯」→まとめて追加 |
| 別の日に写す | 「⋯」→この日を別の日にコピー | 同じ |
| 元に戻す | ↶ ／ Ctrl+Z（やり直しは Ctrl+Shift+Z） | ↶ |

- 編集画面の「定型」（早番・遅番・通し…）を押すと入り・終わり・休憩が一度に入ります。定型は「設定」で変えられます
- 新しく作るとき（ドラッグ・クリック・定型）に6時間を超えていれば、休憩（45分。8時間を超えたら60分）を真ん中に自動で入れます（設定で切れます）。あとから入り・終わりを変えて6時間を超えたときは、編集画面に「休憩を入れましょう」と出ます
- 棒の端をドラッグして縮めたとき、新しい端にかかる休憩は消えます（着いた直後・帰る直前が休憩にならないように）
- 名簿は「メンバー」から。Excel やスプレッドシートの「名前・課・役職」の列をそのまま貼り付けられます。課の欄が空の局長・副局長は「局」に、「広報課長」のような1マスは課と役職の両方に読みます。名簿にもういる名前は、足さずに課と役職を直します
- スマホでは、名前で探すときは右上の虫めがねを押します
- 名前を押すと、その人の6日間のシフトをまとめて見られます（その場で追加・編集も）

## 保存について（大事）

- 名簿とシフトは**この端末のブラウザ（localStorage）にだけ**保存されます。ほかの人の端末には届きません
- 共有するときは「⋯」→**書き出し（JSON）**したファイルを渡し、相手が**読み込み（JSON）**します。読み込むときは「全部を置き換える」か「1つの課だけ入れ替える」を選べるので、GS課と広報課を別々の端末で作って1台にまとめられます
- Excel 用の CSV と印刷（白地）もあります。日別の印刷は A4 横の幅に合わせて描き直し、ページごとに時刻の見出しを付けます
- ブラウザの履歴やサイトデータを消すと消えます。こまめに書き出して控えを取ってください
- リポジトリは公開なので、**実際の名簿をコードやリポジトリに入れない**でください。初めて開いたときは架空の名前のサンプル（50人）が出ます。「サンプルを消して始める」で空にできます

## 本祭支援ツールに入れるとき（メモ）

- データの形は `shift.js` の `normalize()` が基準です（`members`・`shifts`・`roles`・`groups`・`days`・`presets`・`opt`）。時刻は 0:00 からの分（例：9:00 → 540）
- 端末をまたいで共有するには、受信API（`tracking-worker/`）に時刻表（`/api/v1/schedule`）と同じ形で `GET/PUT /api/v1/shifts` を足し、閲覧キー・編集の権限・同時編集の 409 をそのまま使うのが近道です
- GitHub Pages には `.github/workflows/deploy.yml` の許可リストで `shift/` の `index.html`・`shift.css`・`shift.js` だけを載せています（この説明書は載せません）。main に入ると自動で公開されます
- 公開ページはURLを知っていれば誰でも開けます（検索には出ないようにしてあります）。名簿とシフトは開いた端末の中にだけ保存され、ほかの人には見えません
- 地図のページの Service Worker（`sw.js`）は `shift/` を扱わない（いつもネットワークから読む）ようにしてあります。`shift.css`・`shift.js` を直したら、`index.html` の `?v=` の数字を上げてください
