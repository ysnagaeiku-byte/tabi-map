# 渉外局 シフト管理（本祭支援ツール 試作）

たびマップの本祭支援ツールに入れる予定の「シフト作成・管理」を、先に**単独のサイト**として試すためのものです。
地図（`index-google.html`）とは別に動き、地図側のファイルには手を入れていません。

- 対象：渉外局（約50人）。GS課（約15人）・広報課（約30人。部署は情宣・出版）
- 期間：2026年11月4日(水)〜9日(月)の6日間

  | 日付 | 日の名前 |
  |---|---|
  | 11/4(水) | 準準備日 |
  | 11/5(木) | 準備日 |
  | 11/6(金)〜11/8(日) | 本祭1日目・2日目・3日目 |
  | 11/9(月) | 片付け日 |

  日の名前は「⋯」→設定→日付と区分 で直せます
- 開き方：本祭支援ツール（`index-google.html?m=senshu`）の上部のタブの左端「**シフト管理**」を押す。シフトの画面の左上の小さな「‹ たびマップ」（スマホは「‹ マップ」）で支援ツールに戻ります
  - 直接開くときは **https://ysnagaeiku-byte.github.io/tabi-map/shift/** 。手元では `shift/index.html` をブラウザで開くだけでも動きます（サーバーは不要）

## 言葉

| 言葉 | 意味 | 例 |
|---|---|---|
| **役職** | 人ごと。名前の左の小さな印 | 局長・３年・主任・上級・なし |
| **部署** | 広報課の中の分かれ | 情宣・出版（GS課にはなし） |
| **持ち場** | シフトごと。棒の色と棒の中の文字 | 10芝 警備・一体 内警備・10号館 おみくじ… |
| **イベント** | 表のいちばん上に出す時刻 | 開場・公演・出店・撤退… |

## 画面

| 画面 | 内容 |
|---|---|
| **日別** | 横が時刻（6:00〜24:00）、縦がメンバー。1日分のシフトを棒で表示。いちばん上にその日のイベント |
| **6日間** | メンバー×日付の一覧。1マスに入り〜終わり・休憩・持ち場。いちばん上の行に日ごとのイベント |
| 全体／GS課／広報課 | 上の切り替えで、課ごとに分けて見る |

### 並び順

- 課の中は **局長 → ３年 → 主任 → 上級 → なし**（同じ役職の中は名簿に入れた順）
- 広報課は、局長・３年を上に並べ、その下に **情宣**、**出版** の括りを作って、それぞれ主任 → 上級 → なし の順に並べます
  - 「部署の上に並べる」役職は、設定の「役職」の **部署の上** で決めます（はじめは局長・３年）
  - 部署がまだ決まっていない広報課の人は、局長・３年と一緒に上に並びます。「メンバー」で部署を選んでください
- 括りの見出し（GS課・広報課・情宣・出版）を押すと、たためます

### ひと目で分かるようにしたこと

- **持ち場**：棒の色が持ち場の色、棒の中に持ち場の名前。持ち場は当番表の「素材」と「完成版」にある名前と色です
- **シフト不可**：黒い棒（薄い斜線入り）。シフト中の人数・延べ時間・シフトに入る人には数えません。設定で「人数に数えない」にした持ち場も同じ扱いです
- **役職**：名前の左に小さな印（局長＝黄、３年＝橙、主任＝赤、上級＝青、なし＝印なし）。行の左端にも同じ色の線
- **入りと終わり**：持ち場のある棒は、上の行の左端に入り・右端に終わり、下の行に持ち場。棒が短いときは棒の中に持ち場（2行）、棒の横の空いている所に「9:00–9:30」（押すとその棒の編集）。スマホでは名前の下にも「入り–終わり 休憩の始まり」を表示
- **休憩**：棒の中の斜線が休憩（棒の色が透けるので誰の休憩か分かる）。幅があれば「休12:00」、もっと広ければ「休 12:00–12:45」。6日間の画面ではいつも時刻つき
- **シフト中の人数**：日別の下に、30分ごとの人数（休憩中とシフト不可を除く）。目立たないように薄く、多いほど少し明るく。その30分の中で一番少ないときの人数で、途中で人数が変わる枠には下線（パソコンではマウスを重ねると、多いときの人数も出ます）
- **重なり**：同じ人の時間が重なると黄色と黒の枠と「重複」。重なった棒は上下に分けて、両方の端が見えるように
- 「課で色分け」に切り替えると、棒は課の色（GS課＝青緑、広報課＝紫）になり、持ち場は棒の中の文字で分かります
- 凡例には、いま見ている日（6日間なら全体）で使っている持ち場だけが出ます。スマホでは「凡例」を押すと開きます

### 縮尺

- **横**：「−」「＋」で1時間の幅を変える。「全体」で画面の幅に合わせる
- **縦**：「−」「＋」で1人分の行の高さを変える（20〜60px の8段階）。低くすると棒の中は1行になり、名前の下の時刻は隠れます
- どちらもこの端末に覚えておきます

### イベント（表のいちばん上）

- 日別の表の上に、会場・区分ごとの行（全体・10芝・一体・出店・その他）を作って、時刻を棒で出します
  - 始まりと終わりがあるもの（公演など）は棒、**時刻だけ**のもの（開場・撤退など）は小さな旗
  - 「シフト表の上から下まで線を引く」にすると、表の上から下まで点線を引きます（開場・撤退などに）
- 追加：イベントの行の空いている所を押す（押した時刻と行で始まります）。ほかに「⋯」→イベントを追加、6日間の画面ではイベントの行の「＋」
- 編集・削除：イベントを押す。名前・会場や区分（自由に書けます。空欄は「全体」）・日付・時刻・色・メモ。「ほかの日にも同じ時間で作る」で、ほかの日にもまとめて作れます
- 表の左上の「イベント ▾」で、イベントの行をたためます（この端末に覚えておきます）
- パソコンでは時刻の見出しと一緒に上に貼り付いて、下に送っても見えます。スマホは表の高さが足りないので、時刻の見出しだけ貼り付け、イベントは一緒に流れます

## 追加・修正のしかた

| したいこと | パソコン | スマホ |
|---|---|---|
| 追加 | 空いている所をドラッグ（クリックでも可） | 空いている所をタップ |
| 時間を変える | 棒の左右の端をドラッグ | 棒をタップして編集 |
| ずらす・別の人へ | 棒をドラッグ（上下で別の人へ） | 棒をタップして編集 |
| 編集・削除 | 棒をクリック | 棒をタップ |
| 6日間の画面で | マスを押すと追加（1件あるマスはその編集）。もう1件足すときはマスの＋ | 同じ |
| 何人もまとめて | 「まとめて追加」（人×日を選んで一度に。課・部署ごとに全員を選べます） | メニュー「⋯」→まとめて追加 |
| 別の日に写す | 「⋯」→この日を別の日にコピー | 同じ |
| 元に戻す | ↶ ／ Ctrl+Z（やり直しは Ctrl+Shift+Z） | ↶ |

- 編集画面とまとめて追加では、**持ち場を色つきのボタンから選びます**。最後に選んだ持ち場が、次に作るシフトの最初の持ち場になります
- **持ち場を自由に足せます**：編集画面・まとめて追加の「＋ 新しい持ち場」（名前と色、人数に数えるか）か、「⋯」→設定→持ち場。設定では名前・色・並び順・人数に数えるかを変えたり、消したりできます。同じ名前の持ち場は作れません（編集画面で同じ名前を入れると、ある方を選びます）
- 持ち場の色は当番表の「素材」に合わせています。「完成版」では 10芝 警備が緑、10芝 司会照明がサーモン色のところがあります。そちらに合わせるときは、設定で色を変えてください
- 編集画面の「定型」（早番・遅番・通し…）を押すと入り・終わり・休憩が一度に入ります。定型は「設定」で変えられます
- 新しく作るとき（ドラッグ・クリック・定型）に6時間を超えていれば、休憩（45分。8時間を超えたら60分）を真ん中に自動で入れます（設定で切れます。シフト不可には入れません）。あとから入り・終わりを変えて6時間を超えたときは、編集画面に「休憩を入れましょう」と出ます
- 棒の端をドラッグして縮めたとき、新しい端にかかる休憩は消えます（着いた直後・帰る直前が休憩にならないように）
- まとめて追加では、その日にもうシフトがある人を飛ばせます（シフト不可だけの人は、追加する時間と重なるときだけ飛ばします）
- 名簿は「メンバー」から。名前・課・部署・役職を直せます。Excel やスプレッドシートの「名前・課（または部署）・役職」の列をそのまま貼り付けられます
  - 「情宣」「出版」と書けば広報課のその部署に（「出版 主任」のように1マスに部署と役職を書いても読めます）
  - 役職は名前どおりのほか、「1年」はなし、「2年」は上級、「3年」は３年として読みます
  - 名簿にもういる名前は、足さずに課・部署・役職を直します
- 名前で探すときは右上の「名前で検索」（スマホは虫めがね）
- 名前を押すと、その人の6日間のシフトをまとめて見られます（その場で追加・編集、課・部署・役職の変更も）
- 役職の名前・色・並び順・部署の上に並べるか、課と部署の名前は「⋯」→設定 で変えられます

## 保存について（大事）

- 名簿・シフト・イベントは**この端末のブラウザ（localStorage）にだけ**保存されます。ほかの人の端末には届きません
- 共有するときは「⋯」→**書き出し（JSON）**したファイルを渡し、相手が**読み込み（JSON）**します。読み込むときは「全部を置き換える」か「1つの課だけ入れ替える」を選べるので、GS課と広報課を別々の端末で作って1台にまとめられます（役職と持ち場は名前で合わせ、ない持ち場は足します。1つの課だけ入れ替えるときは、イベントはこの端末のものを残します）
- Excel 用の CSV（課・部署・役職・持ち場・シフト中の時間の列あり）と印刷（白地）もあります。日別の印刷は A4 横の幅に合わせて描き直し、ページごとに時刻の見出しを付けます
- ブラウザの履歴やサイトデータを消すと消えます。こまめに書き出して控えを取ってください
- リポジトリは公開なので、**実際の名簿をコードやリポジトリに入れない**でください。初めて開いたときは架空の名前のサンプル（GS課18人・広報課29人、イベントつき）が出ます。「サンプルを消して始める」で空にできます
  - サンプルは、渉外局の実際の当番表（名前を伏せたもの）の形（役職ごとの人数、1時間ほどで持ち場が替わる回し方、パンフの交代、イベントの列）を参考に作りました。時刻やイベントの名前は**だいたい**で、本当の予定ではありません（地図と同じく、公開のリポジトリに本当の時刻は書かない）
- **前の版から**：前の版で入れたデータは、開いたときに新しい形へ移します。前の版のデータは、ブラウザの中にそのまま残しています（`shift_v1`・`shift_v2`。新しい版は `shift_v3` に保存）
  - 前の版のサンプルに手を付けていないとき（50人・名前もそのまま）は、新しいサンプルに入れ替えます。名前を1人でも直していれば、サンプルとは見なさずに移します
  - 役職：局長→局長、副局長→３年、課長・副課長→主任、班長→上級、一般→なし。自分で足した役職は「なし」の上に残します
  - 持ち場（前の版の「役職」）：そのまま残し、当番表の「完成版」にある持ち場（5号館 内警備・10号館 案内警備・一体 内警備・一体 入口警備・一体 物販警備・5号館 控室準備・5号館 控室片付け・10号館 控室片付け・F（フリー）・音響照明 搬入）を足します
  - 広報課の人の部署は空になります。「メンバー」で情宣・出版を選んでください
  - いちばん前の版（局があった版）のデータは、局の人を GS課 に、「担当」を同じ名前の持ち場にします。日の区分は新しい日程になり、日別の表示は 6:00〜24:00 を含むように広げます

## 本祭支援ツールとのつなぎ（メモ）

- 支援ツール側（`index-google.html`）：`buildTabs()` で、本祭支援ツールのときだけタブ列の先頭に `shift/` へのリンク（`a.tab.tab-shift`）を置いています。押す直前に `festResumeSave('shift')` で地図の種類・視点・タブ・追跡を控え、戻ってきて読み込み直したときに元に戻します（控えは2時間まで。ブラウザが地図をそのまま戻したときは使わずに消します）
- シフト側：「‹ たびマップ」は `../index-google.html?m=senshu` へのリンク。支援ツールから来たときは、ブラウザの「戻る」と同じ動き（履歴を増やさず、地図がそのまま戻ることもある）にしています
- 支援ツールの Service Worker は `shift/` を扱わないので、シフトの画面はオフラインでは開けません

## 本祭支援ツールに入れるとき（メモ）

- データの形は `shift.js` の `normalize()` が基準です（`v`:3・`members`・`shifts`・`events`・`roles`・`duties`・`groups`・`days`・`presets`・`opt`）。時刻は 0:00 からの分（例：9:00 → 540、24:00 → 1440）
  - `roles`：役職（人ごと。`member.role`。`top: true` は広報課で部署の上に並べる）
  - `groups[].subs`：部署（広報課の情宣 `jo`・出版 `sh`。`member.sub`）
  - `duties`：持ち場（シフトごと。`shift.duty`。`off: true` は人数に数えない）
  - `events`：`{ d, s, e, name, cat, color, line, note }`。`e === s` は時刻だけ、`cat` は会場・区分（空欄＝全体）、`line` は表の上から下まで線を引く
- 端末をまたいで共有するには、受信API（`tracking-worker/`）に時刻表（`/api/v1/schedule`）と同じ形で `GET/PUT /api/v1/shifts` を足し、閲覧キー・編集の権限・同時編集の 409 をそのまま使うのが近道です
- GitHub Pages には `.github/workflows/deploy.yml` の許可リストで `shift/` の `index.html`・`shift.css`・`shift.js` だけを載せています（この説明書は載せません）。main に入ると自動で公開されます
- 公開ページはURLを知っていれば誰でも開けます（検索には出ないようにしてあります）。名簿とシフトは開いた端末の中にだけ保存され、ほかの人には見えません
- 地図のページの Service Worker（`sw.js`）は `shift/` を扱わない（いつもネットワークから読む）ようにしてあります。`shift.css`・`shift.js` を直したら、`index.html` の `?v=` の数字を上げてください
