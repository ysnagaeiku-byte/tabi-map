# 渉外局 シフト管理（本祭支援ツール 試作）

たびマップの本祭支援ツールに入れる予定の「シフト作成・管理」を、先に**単独のサイト**として試すためのものです。
地図（`index-google.html`）とは別に動き、地図側のファイルには手を入れていません。

- 対象：渉外局（約50人）。局（局長・副局長）・GS課（約15人）・広報課（約30人）
- 期間：2026年11月4日(水)〜9日(月)の6日間（本祭の期間と、その前後）
- 開き方：`shift/index.html` をブラウザで開く（サーバーは不要。ローカルでも動きます）

## 画面

| 画面 | 内容 |
|---|---|
| **日別** | 横が時刻、縦がメンバー。1日分のシフトを棒で表示 |
| **6日間** | メンバー×日付の一覧。1マスに入り〜終わり・休憩・担当 |
| 全体／局／GS課／広報課 | 上の切り替えで、課ごとに分けて見る |

ひと目で分かるようにしたこと：

- **役職**：名前の左に色付きのバッジ（局長＝金、副局長＝橙、課長＝赤、副課長＝桃、班長＝青、一般＝灰の枠だけ）。行の左端にも同じ色の線。「役職で色分け」にすると、棒も役職の色になります
- **入りと終わり**：棒の左端に入り、右端に終わりの時刻。棒が短いときは棒の横に「9:00–10:00」。スマホでは名前の下にも表示
- **休憩**：棒の中の斜線が休憩（棒の色が透けるので誰の休憩か分かる）。6日間の画面では「休 12:00–12:45」と時刻つき
- **人数**：日別の下に、30分ごとの勤務中の人数（休憩中を除く）。全体のときは課ごとの行も
- **重なり**：同じ人の時間が重なると赤い枠

## 追加・修正のしかた

| したいこと | パソコン | スマホ |
|---|---|---|
| 追加 | 空いている所をドラッグ（クリックでも可） | 空いている所をタップ |
| 時間を変える | 棒の左右の端をドラッグ | 棒をタップして編集 |
| ずらす・別の人へ | 棒をドラッグ（上下で別の人へ） | 棒をタップして編集 |
| 編集・削除 | 棒をクリック | 棒をタップ |
| 何人もまとめて | 「まとめて追加」（人×日を選んで一度に） | メニュー「⋯」→まとめて追加 |
| 別の日に写す | 「⋯」→この日を別の日にコピー | 同じ |
| 元に戻す | ↶ ／ Ctrl+Z（やり直しは Ctrl+Shift+Z） | ↶ |

- 編集画面の「定型」（早番・遅番・通し…）を押すと入り・終わり・休憩が一度に入ります。定型は「設定」で変えられます
- 6時間を超えるシフトを作ると、休憩（45分。8時間を超えたら60分）を真ん中に自動で入れます（設定で切れます）
- 名簿は「メンバー」から。Excel やスプレッドシートの「名前・課・役職」の列をそのまま貼り付けられます
- 名前を押すと、その人の6日間のシフトをまとめて見られます（その場で追加・編集も）

## 保存について（大事）

- 名簿とシフトは**この端末のブラウザ（localStorage）にだけ**保存されます。ほかの人の端末には届きません
- 共有するときは「⋯」→**書き出し（JSON）**したファイルを渡し、相手が**読み込み（JSON）**します。Excel 用の CSV と印刷（白地）もあります
- ブラウザの履歴やサイトデータを消すと消えます。こまめに書き出して控えを取ってください
- リポジトリは公開なので、**実際の名簿をコードやリポジトリに入れない**でください。初めて開いたときは架空の名前のサンプル（50人）が出ます。「サンプルを消して始める」で空にできます

## 本祭支援ツールに入れるとき（メモ）

- データの形は `shift.js` の `normalize()` が基準です（`members`・`shifts`・`roles`・`groups`・`days`・`presets`・`opt`）。時刻は 0:00 からの分（例：9:00 → 540）
- 端末をまたいで共有するには、受信API（`tracking-worker/`）に時刻表（`/api/v1/schedule`）と同じ形で `GET/PUT /api/v1/shifts` を足し、閲覧キー・編集の権限・同時編集の 409 をそのまま使うのが近道です
- GitHub Pages の公開は `.github/workflows/deploy.yml` の許可リストにあるファイルだけです。このフォルダはまだリストに入れていないので、公開されません
