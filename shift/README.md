# 渉外局 シフト管理（本祭支援ツール 試作）

たびマップの本祭支援ツールに入れる予定の「シフト作成・管理」を、先に**単独のサイト**として試すためのものです。
地図（`index-google.html`）とは別に動き、地図側のファイルには手を入れていません。

- 対象：渉外局（約50人）。GS課（約15人）・広報課（約30人）
- 期間：2026年11月4日(水)〜9日(月)の6日間

  | 日付 | 日の名前 |
  |---|---|
  | 11/4(水) | 準準備日 |
  | 11/5(木) | 準備日 |
  | 11/6(金)〜11/8(日) | 本祭1日目・2日目・3日目 |
  | 11/9(月) | 片付け日 |

  日の名前は「⋯」→設定→日付と区分 で直せます
- 開き方：公開先 **https://ysnagaeiku-byte.github.io/tabi-map/shift/** を開く。手元では `shift/index.html` をブラウザで開くだけでも動きます（サーバーは不要）

## 画面

| 画面 | 内容 |
|---|---|
| **日別** | 横が時刻（6:00〜24:00）、縦がメンバー。1日分のシフトを棒で表示 |
| **6日間** | メンバー×日付の一覧。1マスに入り〜終わり・休憩・役職 |
| 全体／GS課／広報課 | 上の切り替えで、課ごとに分けて見る |

ひと目で分かるようにしたこと：

- **役職**（シフトごとの持ち場）：棒の色が役職の色、棒の中に役職の名前。役職は当番表の「素材」と同じ名前と色です（一体 警備、一体 司会、一体 照明、5号館 案内警備、10芝 司会照明、9号館 警備、10芝 警備、10芝 開会式、場所自由 撮影、10号館 おみくじ、10号館 パンフ、2号館 パンフ、5号館 外警備、10号館 控え室 警備、協賛、撮影、10号館 控室準備、シフト不可）
- **シフト不可**：黒い棒（薄い斜線入り）。シフト中の人数・延べ時間・シフトに入る人には数えません。設定で「人数に数えない」にした役職も同じ扱いです
- **立場**：課長・副課長・班長は、名前の左に小さなバッジ（課長＝赤、副課長＝桃、班長＝青）。行の左端にも同じ色の線
- **入りと終わり**：役職のある棒は、上の行の左端に入り・右端に終わり、下の行に役職。棒が短いときは棒の横に「9:00–10:00 役職」（押すとその棒の編集）。スマホでは名前の下にも「入り–終わり 休憩の始まり」を表示
- **休憩**：棒の中の斜線が休憩（棒の色が透けるので誰の休憩か分かる）。幅があれば「休12:00」、もっと広ければ「休 12:00–12:45」。6日間の画面ではいつも時刻つき
- **人数**：日別の下に、30分ごとの**シフト中の人数**（休憩中とシフト不可を除く）。その30分の中で一番少ないときの人数で、途中で人数が変わる枠には黄色の下線（パソコンではマウスを重ねると、多いときの人数も出ます）。全体のときは課ごとの行も
- **重なり**：同じ人の時間が重なると黄色と黒の枠と「重複」。重なった棒は上下に分けて、両方の端が見えるように
- 「課で色分け」に切り替えると、棒は課の色（GS課＝青緑、広報課＝紫）になり、役職は棒の中の文字で分かります
- 凡例には、いま見ている日（6日間なら全体）で使っている役職だけが出ます。スマホでは「凡例」を押すと開きます

## 追加・修正のしかた

| したいこと | パソコン | スマホ |
|---|---|---|
| 追加 | 空いている所をドラッグ（クリックでも可） | 空いている所をタップ |
| 時間を変える | 棒の左右の端をドラッグ | 棒をタップして編集 |
| ずらす・別の人へ | 棒をドラッグ（上下で別の人へ） | 棒をタップして編集 |
| 編集・削除 | 棒をクリック | 棒をタップ |
| 6日間の画面で | マスを押すと追加（1件あるマスはその編集）。もう1件足すときはマスの＋ | 同じ |
| 何人もまとめて | 「まとめて追加」（人×日を選んで一度に） | メニュー「⋯」→まとめて追加 |
| 別の日に写す | 「⋯」→この日を別の日にコピー | 同じ |
| 元に戻す | ↶ ／ Ctrl+Z（やり直しは Ctrl+Shift+Z） | ↶ |

- 編集画面とまとめて追加では、**役職を色つきのボタンから選びます**。最後に選んだ役職が、次に作るシフトの最初の役職になります
- **役職を自由に足せます**：編集画面・まとめて追加の「＋ 新しい役職」（名前と色、人数に数えるか）か、「⋯」→設定→役職。設定では名前・色・並び順・人数に数えるかを変えたり、消したりできます。同じ名前の役職は作れません（編集画面で同じ名前を入れると、ある方を選びます）
- 当番表の「素材」では「10芝 警備」が赤と緑の2つありましたが、ここでは赤の1つにしています。分けるときは、設定で名前を変えて足してください（例：「10芝 警備（2）」）
- 編集画面の「定型」（早番・遅番・通し…）を押すと入り・終わり・休憩が一度に入ります。定型は「設定」で変えられます
- 新しく作るとき（ドラッグ・クリック・定型）に6時間を超えていれば、休憩（45分。8時間を超えたら60分）を真ん中に自動で入れます（設定で切れます。シフト不可には入れません）。あとから入り・終わりを変えて6時間を超えたときは、編集画面に「休憩を入れましょう」と出ます
- 棒の端をドラッグして縮めたとき、新しい端にかかる休憩は消えます（着いた直後・帰る直前が休憩にならないように）
- まとめて追加では、その日にもうシフトがある人を飛ばせます（シフト不可だけの人は、追加する時間と重なるときだけ飛ばします）
- 名簿は「メンバー」から。Excel やスプレッドシートの「名前・課・立場」の列をそのまま貼り付けられます。「広報課長」のような1マスは課と立場の両方に、「情宣」「出版」は広報課に読みます。名簿にもういる名前は、足さずに課と立場を直します
- スマホでは、名前で探すときは右上の虫めがねを押します
- 名前を押すと、その人の6日間のシフトをまとめて見られます（その場で追加・編集も）

## 保存について（大事）

- 名簿とシフトは**この端末のブラウザ（localStorage）にだけ**保存されます。ほかの人の端末には届きません
- 共有するときは「⋯」→**書き出し（JSON）**したファイルを渡し、相手が**読み込み（JSON）**します。読み込むときは「全部を置き換える」か「1つの課だけ入れ替える」を選べるので、GS課と広報課を別々の端末で作って1台にまとめられます（役職と立場は名前で合わせ、ない役職は足します）
- Excel 用の CSV（役職・立場・シフト中の時間の列あり）と印刷（白地）もあります。日別の印刷は A4 横の幅に合わせて描き直し、ページごとに時刻の見出しを付けます
- ブラウザの履歴やサイトデータを消すと消えます。こまめに書き出して控えを取ってください
- リポジトリは公開なので、**実際の名簿をコードやリポジトリに入れない**でください。初めて開いたときは架空の名前のサンプル（GS課17人・広報課33人）が出ます。「サンプルを消して始める」で空にできます
- **前の版から**：前の版（局があった版）で入れたデータは、開いたときに新しい形へ移します
  - 局の人は GS課に、局長・副局長は「一般」になります
  - 「担当」は同じ名前の役職になります。ない名前は役職として足します
  - 日の区分は新しい日程になり、11/6〜8 が本祭になります。自分で付けた日の名前はそのまま残ります
  - 日別の表示は 6:00〜24:00 を含むように広げます
  - 前の版のデータは、ブラウザの中の `shift_v1` にそのまま残しています（新しい版は `shift_v2` に保存）。前の版の手を付けていないサンプルだけは、新しいサンプルに入れ替えます

## 本祭支援ツールに入れるとき（メモ）

- データの形は `shift.js` の `normalize()` が基準です（`v`:2・`members`・`shifts`・`roles`・`duties`・`groups`・`days`・`presets`・`opt`）。時刻は 0:00 からの分（例：9:00 → 540、24:00 → 1440）
  - `roles`：立場（人ごと。`member.role`）
  - `duties`：役職（シフトごと。`shift.duty`。`off: true` は人数に数えない）
- 端末をまたいで共有するには、受信API（`tracking-worker/`）に時刻表（`/api/v1/schedule`）と同じ形で `GET/PUT /api/v1/shifts` を足し、閲覧キー・編集の権限・同時編集の 409 をそのまま使うのが近道です
- GitHub Pages には `.github/workflows/deploy.yml` の許可リストで `shift/` の `index.html`・`shift.css`・`shift.js` だけを載せています（この説明書は載せません）。main に入ると自動で公開されます
- 公開ページはURLを知っていれば誰でも開けます（検索には出ないようにしてあります）。名簿とシフトは開いた端末の中にだけ保存され、ほかの人には見えません
- 地図のページの Service Worker（`sw.js`）は `shift/` を扱わない（いつもネットワークから読む）ようにしてあります。`shift.css`・`shift.js` を直したら、`index.html` の `?v=` の数字を上げてください
