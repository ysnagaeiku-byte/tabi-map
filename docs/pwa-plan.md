作成：2026-10-14。同日に実装しました。

## 0. 決めたことと実装（2026-10-14）

| 項目 | 決定 | 実装 |
| --- | --- | --- |
| A. 地図のキー | 埋め込む | 公開の手順（GitHub Actions）に、`GMAP_KEY`・`MAPBOX_KEY` を入れる処理はすでにある。**Secrets の登録はご本人の操作（未登録なら今までどおり端末ごとの入力）** |
| B. 閲覧キー | 本部版は全権限を端末に記憶。配布版は本部が制限を選んで発行し、配布先の端末に記憶 | `#key=…` のリンクで受け取り `localStorage` に記憶。権限は `/api/v1/me`。配布版の発行・取り消しは本部版の「位置情報共有設定」から |
| C. オフライン | 最後に取得した時刻表を表示 | 端末に残し、通信できないときは「前回取得」の印つきで表示。キーが無効になったら消す |

その他の実装：
- メニューに「アプリとして追加」を置いた。Chrome・Edge・Android では追加の確認を出し、iPhone では手順を案内する。追加済みなら出さない。
- Service Worker を `tabimap-v4` にし、支援ツールのアプリ情報・アイコンを最初に保存する一覧へ加えた。

## 2. PWA 化するときの作業

### 2-1. 支援ツール用のアプリ情報（案）

`manifest-senshu.json` を新しく作ります。`id` をドライブ版と変えると、別のアプリとして並べて追加できます。

```json
{
  "id": "./index-google.html?m=senshu",
  "name": "本祭支援ツール（専修大学 鳳祭）",
  "short_name": "本祭支援",
  "start_url": "./index-google.html?m=senshu",
  "scope": "./",
  "display": "standalone",
  "orientation": "any",
  "background_color": "#000000",
  "theme_color": "#000000",
  "lang": "ja",
  "icons": [
    { "src": "icon-senshu-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "icon-senshu-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any" },
    { "src": "icon-senshu-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

### 2-2. ページ側の切り替え

`?m=senshu` のときだけ、`<head>` の早い段階（地図の読み込み前）で次の4つを差し替えます。
- `<link rel="manifest">`
- `apple-mobile-web-app-title`
- `apple-touch-icon`
- `theme-color`

ドライブ版の表示は変えません。

### 2-3. Service Worker

- `CACHE` を上げます（`tabimap-v4`）。
- 起動に必要な資産を最初に保存する一覧に加えます。
  - `fest-vehicle-tracking.js`・`fest-schedule.js`・`manifest-senshu.json`・支援ツールのアイコン
  - 地図データ（`fest-*.json`）は大きいので、今どおり使ったときに保存します。
- 新しい版に切り替わったら「新しい版に更新しました」と短く出します（`controllerchange`）。
- 通信できないときは、帯や一覧に「オフライン」と出します。地図タイルは Google の規約上、保存しません。

### 2-4. 追加の導線

| 端末 | 方法 |
| --- | --- |
| PC（Chrome・Edge）・Android | メニューに「アプリとして追加」ボタン（`beforeinstallprompt` を使う）。対応しないブラウザでは出さない |
| iPhone・iPad | Safari の共有ボタン →「ホーム画面に追加」の手順を案内 |
| Mac（Safari） | ファイル →「Dock に追加」 |

### 2-5. アイコン

支援ツール用のアイコン（192・512・maskable 512・apple-touch 180）を作ります。maskable は中央 80% に収まる図柄にします。

## 3. 先に決めておきたいこと

**A. 地図のキー（Google Maps・Mapbox）の配り方**
- 今は端末ごとに手入力です。
- iPhone・iPad のホーム画面アプリは Safari と保存場所が別のため、追加したアプリでもう一度入力が要ります。
- GitHub の Actions Secrets（`GMAP_KEY`・`MAPBOX_KEY`）に登録すれば、公開時に自動で入り、入力は不要になります。
  - 登録はご本人の操作です。
  - キーはリファラー制限で守ります。
- **PWA 化の前に登録しておくのがおすすめです。**

**B. 閲覧キーの保存**
- 今はタブを閉じると消えます（sessionStorage）。ホーム画面アプリでは、アプリを閉じるたびに入れ直しになります。
- 本部の専用端末向けに「この端末に記憶する」を用意するか決めてください。記憶すると、端末を手にした人は誰でも時刻表と車両の位置を見られます。

**C. オフライン時の表示**
- 受信APIに届かないとき、最後に取得した時刻表を端末に残して表示するか決めてください。
- 残すと、通信が切れても帯が出ます。その代わり、端末内に開錠・施錠時刻が残ります。

**D. ドライブ版との関係**
- 同じ場所（同じ URL の範囲）にあるため、ドライブ版と支援ツールは別アプリとして並べて追加できます（`id` が違う）。
- 完全に分けたい場合は、支援ツール専用のパス（例：`/tabi-map/senshu/`）を作る方法もあります。こちらは作業が増えます。

**E. アイコンの図柄**
- 例：地図ピン＋提灯、鳳祭の文字など。

## 4. 端末ごとの注意

- **スリープ防止が効く範囲**
  - ページ（アプリ）が前面にあるときだけ効きます。
  - 別のタブ・アプリに切り替えると外れ、戻ると自動で取り直します。
  - 蓋を閉じる・手動でスリープさせる場合は防げません。
- **iPhone・iPad**
  - ホーム画面アプリでのスリープ防止は、iOS 18.4 以降で動きます。それより前は、設定の「自動ロック」を「なし」にしてください。
- **電池**：スリープ防止中は電池の減りが早くなります。本部の端末は電源につないでください。メニュー「画面を消さない」でオフにできます。
- **運転手のスマホ**：PWA は不要です。Traccar Client が位置を送ります。
