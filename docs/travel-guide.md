# 温泉郷の紹介・観光特集（guide/）

Google版（ドライブ支援）だけの機能です。本祭支援ツール（`?m=senshu`）と研究版（track.html）には出しません。

## 何を表示しているか

| 対象 | 件数 | 写真 | 表示場所 |
|---|---:|---:|---|
| 温泉郷（既存の `ONSEN_GO`） | 110 | 109 | カスタムタブの「♨ 温泉郷」で表示するピンの吹き出し（紹介文50字以内・代表写真1点） |
| 観光特集（47都道府県） | 1045 | 348 | タブ「観光特集」（県・カテゴリ・キーワードで絞り込み、20件ずつ表示） |

- 写真は **取得済み・被写体の目視確認済み** のものだけです（376点、長辺640pxのWebP、計約18MB）。写真のない項目は「写真は準備中です」の無地表示で、別の写真で代用しません。
- 写真の近くに撮影者・ライセンス・ファイル説明ページ（Wikimedia Commons）へのリンクを出します。全点の一覧は「写真の出典一覧」。
- 写真に行った変更は「表示用に縮小・WebP形式に変換（内容の加工なし）」だけです。
- 温泉郷は「名前＋都道府県」で照合しています（配列の位置では結びつけない）。座標・規模・入湯税・順序・ピンの表示条件は変えていません。
- 観光特集のカテゴリ：絶景・景勝地／温泉／歴史・文化／レジャー・体験／グルメ。
- カードに出すのは写真・名称・所在地・カテゴリ・紹介文・見どころ・時季・公式サイトへのリンク。「移動」と「確認状況」の行は出さない（2026-10-28 廃止）。公式サイトのリンクは、個別ページを確認した項目（71件）は「公式ページ」、それ以外（974件）は「県の観光公式サイト」と表示する。

## 「地図で見る」の位置の決め方

観光特集の項目は大半（965件）に座標がありません。県庁・市役所などの代わりの位置には置かず、次の順に探します。

1. 温泉郷と同じ温泉（81件）：たびマップの温泉郷データの位置
2. 前に見つけた位置（端末に30日保存、`tabi_tour_geo`）
3. Google の施設検索（名称＋市町村＋都道府県）。住所が同じ都道府県で、名前が似ている候補だけ使う（1回ごとに Places の Text Search を1回使う）
4. 資料の参考座標（80件）。「参考位置（駐車場・入口ではありません）」と表示
5. 見つからなければ上部の検索に名称を入れ、候補から選んでもらう

位置はいずれも駐車場・入口・登山口を示すものではない旨を表示しています。

## データの作り直し

```bash
python3 -I tools/build-travel-guide.py <引き継ぎ素材集を展開したフォルダ>
```

- 照合漏れ・重複キー・紹介文50字超・47都道府県と5カテゴリ・写真ファイル・撮影者名・ライセンスURL・ファイル説明ページURLを検証し、問題があれば書き出さずに止まります。
- 作り直したら `index-google.html` の `GUIDE_V` を上げます。写真はファイル名が中身のハッシュなので、差し替えると自動で別名になります。
- 素材集（zip・展開したフォルダ）は公開リポジトリに入れません（`.gitignore` 済み）。Pages には `guide/` の JSON と写真だけを載せます（`.github/workflows/deploy.yml` の許可リスト）。

## 端末への保存（Service Worker）

- 写真は別の保存先（`tabimap-photos-v1`）に、見た分だけ新しい順に200枚まで。超えたら古いものから消します。起動時に写真をまとめて保存することはしません。
- `?v=` 付きのデータは、新しい版を保存したら同じファイルの古い版を消します（更新後に古いデータと混ざらない）。
- 位置のAPI・認証付きの通信・GET以外はこれまでどおり保存しません。
